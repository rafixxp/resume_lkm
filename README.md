# Resume LKM

Platform pembelajaran kepemimpinan yang menyediakan berbagai materi referensi untuk pengembangan diri dan kemampuan memimpin.

## 📚 Tentang Proyek

Resume LKM adalah aplikasi web berbasis Vue 3 yang dirancang untuk mengelola dan menampilkan materi-materi kepemimpinan secara terstruktur. Platform ini menyajikan berbagai topik penting dalam pengembangan organisasi dan kepemimpinan melalui antarmuka yang modern dan responsif.

## 🎯 Fitur Utama

- **Katalog Materi**: Koleksi materi kepemimpinan yang terorganisir dengan baik
- **Navigasi Mudah**: Sistem routing yang intuitif untuk akses materi
- **Desain Responsif**: Tampilan yang optimal di berbagai ukuran layar
- **UI Modern**: Antarmuka pengguna yang bersih dan elegan dengan TailwindCSS

## 🛠️ Teknologi yang Digunakan

- **Vue 3**: Framework JavaScript progresif dengan Composition API
- **Vite**: Build tool yang cepat dan efisien
- **Vue Router**: Manajemen routing untuk navigasi antar halaman
- **TailwindCSS**: Framework CSS untuk styling modern
- **Three.js**: Library untuk grafis 3D

## 📦 Instalasi

```bash
# Install dependencies
npm install

# Jalankan server development
npm run dev

# Build untuk produksi
npm run build

# Preview build produksi
npm run preview
```

## 📂 Materi Tersedia

- Analisa Organisasi
- Analisis Pengembangan Masyarakat
- Dinamika Sosial dan Politik
- Kekeluargaan
- Otoritas Informasi
- Pengembangan dan Pembangunan Organisasi
- Retorika

## 🚀 Pengembangan

Proyek ini menggunakan struktur Vue 3 SFC (Single File Components) dengan `<script setup>` untuk pengelolaan komponen yang lebih efisien.
